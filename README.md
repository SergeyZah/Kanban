# KanbanBoard

KanbanBoard is a Node.js application to create your success plan.

## Features

- User login and registration
- Creating new tasks
- Editing and deleting current tasks
- The ability to change deadlines, topic, and task description

## Stack

- React 19
- JavaScript XML

## Requirements

- React 19+
- npm 10+

## Installation

```bash
npm install
```

## Run Locally

Development mode:

```bash
npm run dev
```

Production build:

```bash
npm run build
npm run start
```

Lint:

```bash
npm run lint
```

Tests:

```bash
npm test
```

## Environment

The app uses `BASE_URL` for API requests.

Example:

```env
BASE_URL=https://wedev-api.sky.pro/api/kanban/
```
